# Day 47: Wealth Distribution Simulator

Set trading rules and watch wealth concentrate in real time.

Live at https://varad-patel.github.io/365projects/47/ (part of [365 projects in 365 days](https://varad-patel.github.io/365projects/), section "Economics × Data Science").

| | |
|---|---|
| Question | If equal agents make nothing but fair bets with each other, where does the wealth end up, and what does a tax or a bias change? |
| One finding | With 500 equal agents making fair bets of 10% of the poorer party's wealth, the Gini index reaches 87.9 after 1,000 rounds and the poorest half hold 0.04% of everything; a 1% wealth tax a round, shared out equally, holds the index at 37.6. |
| Main limit | Nothing is produced and the agents are identical, so the model isolates what chance alone does to wealth and says nothing about work, skill, inheritance or whether the outcome is just. |
| PPE concept | Distributive justice |
| Skills | Agent-based modelling |
| Data | None. Everything is computed in the browser. |

## Files

* `index.html`: the page, including the write-up (the idea, how it works, what it cannot tell you, extensions).
* `logic.js`: the model, with no DOM code, so it can be tested on its own.
* `app.js`: the interface, built on the shared kit in `../kit/`.
* `logic.test.mjs`: tests for the model. Run them from the repository root with `node --test 365projects/47/logic.test.mjs`.

This file is generated by `scripts/build_data.py` from `meta.json` and `data/challenge.tsv`.
