# Day 15: Sorites and Fuzzy Logic

Click where you think a heap starts and compare your boundary with crisp and fuzzy models.

Live at https://varad-patel.github.io/365projects/15/ (part of [365 projects in 365 days](https://varad-patel.github.io/365projects/), section "Philosophy × Data").

| | |
|---|---|
| Question | Where does a heap start, and what do a sharp line, a fuzzy curve and a truth-value gap each make of your answer? |
| One finding | With marks at 10, 100 and 1,000 grains the sorites argument takes 990 steps; in Łukasiewicz logic the least true step is true to degree 0.979, yet the 990 shortfalls add up to exactly 1, while classical logic makes 989 steps true and one false. |
| Main limit | The tool reads one visitor's three marks in three ways; it cannot say where a heap really starts or which theory of vagueness is right, and its own exact bounds ignore higher-order vagueness. |
| PPE concept | Vagueness |
| Skills | Fuzzy sets, membership functions |
| Data | None. Everything is computed in the browser. |

## Files

* `index.html`: the page, including the write-up (the idea, how it works, what it cannot tell you, extensions).
* `logic.js`: the model, with no DOM code, so it can be tested on its own.
* `app.js`: the interface, built on the shared kit in `../kit/`.
* `logic.test.mjs`: tests for the model. Run them from the repository root with `node --test 365projects/15/logic.test.mjs`.

This file is generated by `scripts/build_data.py` from `meta.json` and `data/challenge.tsv`.
