# Day 69: Bubble Detector

Pick an asset and get a bubble score based on whether prices look explosive.

Live at https://varad-patel.github.io/365projects/69/ (part of [365 projects in 365 days](https://varad-patel.github.io/365projects/), section "Economics × Finance").

| | |
|---|---|
| Question | Does an asset's price look explosive, the way a bubble would make it, and how often does the test that says so raise a false alarm? |
| One finding | Bitcoin's monthly price is explosive by the GSADF test (3.90 against a 5% critical value of 2.33, a verdict that survives Bitcoin's own upward trend, which raises the false-alarm rate on random walks from 6 in 100 to 28), with one dated episode from May 2017 to March 2018, but its bubble score in April 2026, its last month of data, is 55, while gold's in September 2026 is 99. |
| Main limit | The test finds explosive growth, not its cause: fundamentals can grow explosively too, and it cannot say when an episode will end. |
| PPE concept | Bubbles, rationality |
| Skills | SADF unit-root test |
| Data | Coin Metrics, FHFA, Bureau of Labor Statistics, World Bank |

## Files

* `index.html`: the page, including the write-up (the idea, how it works, what it cannot tell you, extensions).
* `logic.js`: the model, with no DOM code, so it can be tested on its own.
* `app.js`: the interface, built on the shared kit in `../kit/`.
* `logic.test.mjs`: tests for the model. Run them from the repository root with `node --test 365projects/69/logic.test.mjs`.

This file is generated by `scripts/build_data.py` from `meta.json` and `data/challenge.tsv`.
