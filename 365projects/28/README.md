# Day 28: Two Envelopes Paradox

Choose a prior for the envelope amounts and play the game to see when switching helps.

Live at https://varad-patel.github.io/365projects/28/ (part of [365 projects in 365 days](https://varad-patel.github.io/365projects/), section "Philosophy × Data").

| | |
|---|---|
| Question | When does switching envelopes help, and which step of the argument for always switching fails? |
| One finding | With the smaller amount equally likely to be 1, 2, 4 and so on up to 512, always keeping and always switching both average exactly 153.45 a round, while switching only on 512 or less averages 179.05, which is 16.7% more. |
| Main limit | The tool is exact only for a prior you choose yourself, so it cannot say what to do when you know nothing about how the amounts were set. |
| PPE concept | Decision under uncertainty |
| Skills | Priors, expected value |
| Data | None. Everything is computed in the browser. |
