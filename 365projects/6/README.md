# Day 6: Trolley Problem Lab

Answer ten trolley variants and see which ethical theories your answers match and where you are inconsistent.

Live at https://varad-patel.github.io/365projects/6/ (part of [365 projects in 365 days](https://varad-patel.github.io/365projects/), section "Philosophy × Data").

| | |
|---|---|
| Question | Which moral theories do your answers to ten trolley cases match, and where do those answers pull against each other? |
| One finding | Six theories written as rules agree on only one of the ten cases, and of the 1,024 possible sets of answers only 46 never permit a harder case while forbidding an easier one. |
| Main limit | Ten yes-or-no answers to coded thought experiments cannot identify the theory a person holds, and the coding of each case is itself contestable. |
| PPE concept | Consequentialism versus deontology |
| Skills | Rule-based scoring, consistency checks |
| Data | None. Everything is computed in the browser. |

## Files

* `index.html`: the page, including the write-up (the idea, how it works, what it cannot tell you, extensions).
* `logic.js`: the model, with no DOM code, so it can be tested on its own.
* `app.js`: the interface, built on the shared kit in `../kit/`.
* `logic.test.mjs`: tests for the model. Run them from the repository root with `node --test 365projects/6/logic.test.mjs`.

This file is generated by `scripts/build_data.py` from `meta.json` and `data/challenge.tsv`.
