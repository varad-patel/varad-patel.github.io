# Day 3: Monty Hall Monte Carlo

Play the game yourself, then run 100,000 simulated games under switch and stay strategies and watch the odds converge.

Live at https://varad-patel.github.io/365projects/3/ (part of [365 projects in 365 days](https://varad-patel.github.io/365projects/), section "Philosophy × Data").

| | |
|---|---|
| Question | Should you switch doors in the Monty Hall game, and why does the answer depend on what the host knows? |
| One finding | In 100,000 simulated games switching won 66.9% and staying 33.1%; when the host opens a door at random instead, the two strategies tie. |
| Main limit | The 2/3 answer holds only under the stated rules: a host who knows where the car is, must open a goat door and must offer the switch. |
| PPE concept | Rational choice under uncertainty |
| Skills | Monte Carlo simulation, interactive charts |
| Data | None. Everything is computed in the browser. |
