# Day 45: Laffer Curve Explorer

Choose behavioural responses and see the revenue curve and the revenue-maximising rate.

Live at https://varad-patel.github.io/365projects/45/ (part of [365 projects in 365 days](https://varad-patel.github.io/365projects/), section "Economics × Data Science").

| | |
|---|---|
| Question | At what tax rate does revenue peak, and how much does the answer depend on how strongly people are assumed to respond? |
| One finding | For a top-bracket tax with a Pareto parameter of 1.5, revenue peaks at 72.7% with an elasticity of taxable income of 0.25, but anywhere from 84.7% to 62.5% across the range of estimates (0.12 to 0.40) that the main review calls the best available. |
| Main limit | The elasticities are inputs, not estimates for any country, and the rate that raises the most revenue is not the best rate for a government that gives any weight to the people taxed. |
| PPE concept | Tax policy |
| Skills | Optimisation, sensitivity analysis |
| Data | None. Everything is computed in the browser. |

## Files

* `logic.test.mjs`: tests for the model. Run them from the repository root with `node --test 365projects/45/logic.test.mjs`.
