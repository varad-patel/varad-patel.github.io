# Day 80: Currency Prediction Lab

Pick a currency pair and see model forecasts against a random walk with a scorecard.

Live at https://varad-patel.github.io/365projects/80/ (part of [365 projects in 365 days](https://varad-patel.github.io/365projects/), section "Economics × Finance").

| | |
|---|---|
| Question | Can simple forecasting models beat the random walk at predicting exchange rates? |
| One finding | Twelve months ahead, with forecasts made from 1990, three models scored against the random walk for 22 currencies against the dollar came out ahead in 13 of 66 comparisons and by more than chance would usually allow in only one, fewer than the 1.7 that luck alone would give, while the random walk was ahead by that margin in 18. |
| Main limit | The models see only each rate's own past, so the page tests time-series forecasting, not the economic models built on money, prices and interest rates that Meese and Rogoff tested. |
| PPE concept | Exchange rates |
| Skills | Forecast evaluation |
| Data | Federal Reserve Board H.10 Foreign Exchange Rates |

## Files

* `index.html`: the page, including the write-up (the idea, how it works, what it cannot tell you, extensions).
* `logic.js`: the model, with no DOM code, so it can be tested on its own.
* `app.js`: the interface, built on the shared kit in `../kit/`.
* `logic.test.mjs`: tests for the model. Run them from the repository root with `node --test 365projects/80/logic.test.mjs`.

This file is generated by `scripts/build_data.py` from `meta.json` and `data/challenge.tsv`.
