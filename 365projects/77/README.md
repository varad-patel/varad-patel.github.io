# Day 77: Compound Interest Universe

Enter savings and return assumptions and see how small differences compound over decades.

Live at https://varad-patel.github.io/365projects/77/ (part of [365 projects in 365 days](https://varad-patel.github.io/365projects/), section "Economics × Finance").

| | |
|---|---|
| Question | How much do small differences in return, fees, start age and pay-ins change what savings grow to over decades? |
| One finding | Saving $200 a month from 25 to 65 at an assumed 5% before fees of 0.1%, with 2% inflation, ends at $130,832 in today's money; fees one point higher leave 22.5% less, nearly as much as starting five years later (24.9% less), and a saver who is 35 today needs $300 a month to end with about the same. |
| Main limit | Returns are assumed constant and known, so the tool shows the arithmetic of compounding, not what any real investment will do, and it is not financial advice. |
| PPE concept | Patience and wealth |
| Skills | Exponential growth |
| Data | None. Everything is computed in the browser. |
