# Day 20: Bertrand's Paradox Simulator

Choose a method for picking random chords and watch the probability change with it.

Live at https://varad-patel.github.io/365projects/20/ (part of [365 projects in 365 days](https://varad-patel.github.io/365projects/), section "Philosophy × Data").

| | |
|---|---|
| Question | What is the probability that a random chord of a circle is longer than the side of the inscribed equilateral triangle? |
| One finding | With 100,000 chords per method, 33.1% are long when the endpoints are random, 50.1% when a point on a random radius is and 25.2% when the midpoint is, and only the random-radius method keeps its answer when the question is put to a smaller circle. |
| Main limit | The simulation shows that each procedure has its own answer; it cannot say which procedure "at random" means, because the question does not. |
| PPE concept | Principle of indifference |
| Skills | Geometric probability |
| Data | None. Everything is computed in the browser. |
