# Day 12: Syllogism Validator

Type a syllogism and get a verdict with a Venn diagram showing why it holds or fails.

Live at https://varad-patel.github.io/365projects/12/ (part of [365 projects in 365 days](https://varad-patel.github.io/365projects/), section "Philosophy × Data").

| | |
|---|---|
| Question | Does the conclusion of a three-term argument have to follow from its two premises, and if not, what would a world look like where it fails? |
| One finding | Of the 256 possible syllogistic forms, exhaustive model checking finds 15 valid on the modern reading and 24 once every term is assumed to have at least one member. |
| Main limit | Validity is not truth: the tool checks whether the conclusion follows from the premises, not whether the premises are right or the words mean the same thing each time. |
| PPE concept | Aristotelian logic |
| Skills | Set theory, model checking |
| Data | None. Everything is computed in the browser. |

## Files

* `index.html`: the page, including the write-up (the idea, how it works, what it cannot tell you, extensions).
* `logic.js`: the model, with no DOM code, so it can be tested on its own.
* `app.js`: the interface, built on the shared kit in `../kit/`.
* `logic.test.mjs`: tests for the model. Run them from the repository root with `node --test 365projects/12/logic.test.mjs`.

This file is generated by `scripts/build_data.py` from `meta.json` and `data/challenge.tsv`.
