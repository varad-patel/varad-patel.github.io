# Day 22: Gödel Numbering Encoder

Type a formula to get its Gödel number, or paste a number to decode it back into a formula.

Live at https://varad-patel.github.io/365projects/22/ (part of [365 projects in 365 days](https://varad-patel.github.io/365projects/), section "Philosophy × Data").

| | |
|---|---|
| Question | How can a formula of arithmetic be turned into a single whole number and recovered from it again? |
| One finding | Of the whole numbers from 1 to 1,000,000, only 781 are the code of any string of the 17 symbols and exactly three are well-formed formulas: 2,430 (0=0), 85,050 (0=S0) and 262,500 (S0=0). |
| Main limit | The page carries out only the numbering and a syntax check; it contains no axioms, proofs or provability predicate, so it illustrates the first step of Gödel's argument and proves nothing about incompleteness. |
| PPE concept | Incompleteness |
| Skills | Prime factorisation, number theory |
| Data | None. Everything is computed in the browser. |

## Files

* `index.html`: the page, including the write-up (the idea, how it works, what it cannot tell you, extensions).
* `logic.js`: the model, with no DOM code, so it can be tested on its own.
* `app.js`: the interface, built on the shared kit in `../kit/`.
* `logic.test.mjs`: tests for the model. Run them from the repository root with `node --test 365projects/22/logic.test.mjs`.

This file is generated by `scripts/build_data.py` from `meta.json` and `data/challenge.tsv`.
