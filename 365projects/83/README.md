# Day 83: Credit Risk Model

Enter a borrower profile and get a default probability with a fairness check.

Live at https://varad-patel.github.io/365projects/83/ (part of [365 projects in 365 days](https://varad-patel.github.io/365projects/), section "Economics × Finance").

| | |
|---|---|
| Question | Given a borrower's profile, how likely are they to default, do the model's forecasts come true as often as they say, and does it treat groups of borrowers alike? |
| One finding | Fitted without sex on 19,998 Taiwanese cardholders and checked on 10,002 held out, the model's average forecast is 21.8% for women when 20.6% defaulted and 23.7% for men when 24.4% did; with sex as an input it comes within 0.6 points for both, and at a 50% cut-off it flags 4.3% of women and 6.3% of men who repaid. |
| Main limit | The data come from one bank in Taiwan in 2005, several of their codes are undefined, and the forecasts are an illustration of the method, not a lending decision. |
| PPE concept | Credit and fairness |
| Skills | Logistic regression, calibration |
| Data | UCI Machine Learning Repository (Default of Credit Card Clients) |

## Files

* `logic.js`: the model, with no DOM code, so it can be tested on its own.
* `app.js`: the interface, built on the shared kit in `../kit/`.
* `logic.test.mjs`: tests for the model. Run them from the repository root with `node --test 365projects/83/logic.test.mjs`.
