# Day 61: Gold Price Forecaster

Pick a horizon and see forecasts with uncertainty bands and a running scorecard of past forecasts against a naive baseline.

Live at https://varad-patel.github.io/365projects/61/ (part of [365 projects in 365 days](https://varad-patel.github.io/365projects/), section "Economics × Finance").

| | |
|---|---|
| Question | Can a time-series model forecast the price of gold better than assuming it will not change? |
| One finding | Over 468 forecasts made from 1985 to 2023, twelve months ahead, an ARIMA model chosen by AICc at each date missed by 12.1% on average against 12.3% for the latest price unchanged, a gap the Diebold-Mariano test cannot tell from chance (p = 0.657), and its 80% band held the outcome 91% of the time. |
| Main limit | The World Bank's price is a monthly average, which makes changes slightly predictable even when the market price is a random walk, so a small edge here is not evidence against market efficiency. |
| PPE concept | Forecasting, market efficiency |
| Skills | ARIMA, backtesting, scheduled data refresh |
| Data | World Bank Commodity Price Data (The Pink Sheet) |

## Files

* `index.html`: the page, including the write-up (the idea, how it works, what it cannot tell you, extensions).
* `logic.js`: the model, with no DOM code, so it can be tested on its own.
* `app.js`: the interface, built on the shared kit in `../kit/`.
* `logic.test.mjs`: tests for the model. Run them from the repository root with `node --test 365projects/61/logic.test.mjs`.

This file is generated by `scripts/build_data.py` from `meta.json` and `data/challenge.tsv`.
