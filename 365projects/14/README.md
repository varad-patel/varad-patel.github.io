# Day 14: Simpson's Paradox Finder

Drop in a CSV and the app searches for trends that reverse when groups are split, showing both charts side by side.

Live at https://varad-patel.github.io/365projects/14/ (part of [365 projects in 365 days](https://varad-patel.github.io/365projects/), section "Philosophy × Data").

| | |
|---|---|
| Question | Does a trend in a whole table still point the same way once the table is split into groups? |
| One finding | At Berkeley in 1973 men were admitted at 44.5% and women at 30.4% across the six largest departments, yet women had the higher rate in four of the six and are 4.3 points ahead once both sexes are given the same spread of applications. |
| Main limit | The whole table and the split table are both correct, and only a view about what causes what, which no CSV contains, can say which one answers the question. |
| PPE concept | Causation versus correlation |
| Skills | Group-by analysis, in-browser data processing |
| Data | Bickel, Hammel and O'Connell (1975), Charig et al. (1986) |

## Files

* `index.html`: the page, including the write-up (the idea, how it works, what it cannot tell you, extensions).
* `logic.js`: the model, with no DOM code, so it can be tested on its own.
* `app.js`: the interface, built on the shared kit in `../kit/`.
* `logic.test.mjs`: tests for the model. Run them from the repository root with `node --test 365projects/14/logic.test.mjs`.
