# Day 90: Ranked-Choice Election Engine

Enter or upload ballots, or generate a simulated electorate, and see round-by-round transfers and results.

Live at https://varad-patel.github.io/365projects/90/ (part of [365 projects in 365 days](https://varad-patel.github.io/365projects/), section "Politics × Data").

| | |
|---|---|
| Question | How does an instant-runoff count move from first preferences to a winner, and what happens to ballots that run out of candidates? |
| One finding | Counting all 52,369 formal ballots from Wollondilly at the 2023 New South Wales election reproduces the published distribution of preferences at all five counts: Judy Hannan, 4,126 votes behind on first preferences, wins 21,588 to 20,312, while 10,469 ballots (20.0%) are exhausted, 9,816 of them from voters who numbered a single square. |
| Main limit | The real ballots are the Electoral Commission's reading of each paper, and the counting options cover common rules, not any one jurisdiction's law in full. |
| PPE concept | Electoral design |
| Skills | Algorithms, CSV handling |
| Data | NSW Electoral Commission |

## Files

* `index.html`: the page, including the write-up (the idea, how it works, what it cannot tell you, extensions).
* `logic.js`: the model, with no DOM code, so it can be tested on its own.
* `app.js`: the interface, built on the shared kit in `../kit/`.
* `logic.test.mjs`: tests for the model. Run them from the repository root with `node --test 365projects/90/logic.test.mjs`.

This file is generated by `scripts/build_data.py` from `meta.json` and `data/challenge.tsv`.
