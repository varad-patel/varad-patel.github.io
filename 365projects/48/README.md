# Day 48: Monopoly Pricing Simulator

Set demand and costs and see monopoly price, output and welfare loss against competition.

Live at https://varad-patel.github.io/365projects/48/ (part of [365 projects in 365 days](https://varad-patel.github.io/365projects/), section "Economics × Data Science").

| | |
|---|---|
| Question | What price does a single seller choose, and how much surplus is lost compared with a price equal to marginal cost? |
| One finding | With demand price = 100 - quantity and a marginal cost of 20, a monopolist sells 40 units at 60 instead of 80 at 20, earns 1,600 and destroys 800 of surplus, exactly a quarter of what the market could have produced. |
| Main limit | The answer depends on the shape of the demand curve far from today's price, which is rarely known, and the model is static: no entry, no innovation, no price discrimination. |
| PPE concept | Market power |
| Skills | Marginal revenue optimisation |
| Data | None. Everything is computed in the browser. |

## Files

* `index.html`: the page, including the write-up (the idea, how it works, what it cannot tell you, extensions).
* `logic.js`: the model, with no DOM code, so it can be tested on its own.
* `app.js`: the interface, built on the shared kit in `../kit/`.
* `logic.test.mjs`: tests for the model. Run them from the repository root with `node --test 365projects/48/logic.test.mjs`.

This file is generated by `scripts/build_data.py` from `meta.json` and `data/challenge.tsv`.
