# Day 68: Crypto Volatility Lab

Pick a coin from open price data and see volatility regimes and a risk forecast.

Live at https://varad-patel.github.io/365projects/68/ (part of [365 projects in 365 days](https://varad-patel.github.io/365projects/), section "Economics × Finance").

| | |
|---|---|
| Question | How volatile is a cryptocurrency now, how long do its storms last, and would a standard risk model's warnings have held up? |
| One finding | Fitted to Bitcoin's daily prices from 2018 to May 2026, GARCH(1,1) has a persistence of 0.961 (a volatility shock halves in about 17.5 days), and its 99% value at risk was exceeded on 23 of 2,064 backtest days (1.11%), against 46 days for the RiskMetrics rule. |
| Main limit | The model describes the size of price moves in the window it was fitted to, not their direction, and no window contains the crash that has not happened yet. |
| PPE concept | Speculation |
| Skills | GARCH |
| Data | Coin Metrics |

## Files

* `index.html`: the page, including the write-up (the idea, how it works, what it cannot tell you, extensions).

* `app.js`: the interface, built on the shared kit in `../kit/`.
* `logic.test.mjs`: tests for the model. Run them from the repository root with `node --test 365projects/68/logic.test.mjs`.
