# Day 8: Hedonic Treadmill Simulator

Set an income path and an adaptation rate and see predicted happiness over time next to open survey panel data.

Live at https://varad-patel.github.io/365projects/8/ (part of [365 projects in 365 days](https://varad-patel.github.io/365projects/), section "Philosophy × Data").

| | |
|---|---|
| Question | If people get used to higher incomes, how quickly does a raise stop making them happier, and does the pattern show up in what countries report? |
| One finding | Across 139 countries, a doubling of income per person between 2010-12 and 2023-25 went with about one more point of life evaluation, so country averages show no treadmill over this period. |
| Main limit | Adaptation happens to individuals, and national averages over thirteen survey periods cannot show whether any person got used to their income. |
| PPE concept | Hedonic adaptation |
| Skills | Difference equations, curve fitting |
| Data | World Happiness Report 2026, World Bank |

## Files

* `index.html`: the page, including the write-up (the idea, how it works, what it cannot tell you, extensions).
* `logic.js`: the model, with no DOM code, so it can be tested on its own.
* `app.js`: the interface, built on the shared kit in `../kit/`.
* `logic.test.mjs`: tests for the model. Run them from the repository root with `node --test 365projects/8/logic.test.mjs`.

This file is generated by `scripts/build_data.py` from `meta.json` and `data/challenge.tsv`.
