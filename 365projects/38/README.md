# Day 38: Price Elasticity Lab

Upload sales data and get a demand-curve estimate and the revenue-maximising price.

Live at https://varad-patel.github.io/365projects/38/ (part of [365 projects in 365 days](https://varad-patel.github.io/365projects/), section "Economics × Data Science").

| | |
|---|---|
| Question | What do your sales records say about how buyers respond to price, and is there a price they support as the one that brings in most revenue? |
| One finding | On 120 simulated days with prices set by rota and a true elasticity of −1.8 the fit returns −1.80 (95% interval −1.92 to −1.69), but on 150 simulated days where the seller raises the price when demand is strong and the truth is −1.5 it returns −0.11. |
| Main limit | The slope describes sales at prices somebody chose, so if prices followed demand it is not the buyers' response, and nothing in the table can show whether they did. |
| PPE concept | Demand and elasticity |
| Skills | Log-log regression |
| Data | None. Everything is computed in the browser. |

## Files

* `index.html`: the page, including the write-up (the idea, how it works, what it cannot tell you, extensions).
* `logic.js`: the model, with no DOM code, so it can be tested on its own.
* `app.js`: the interface, built on the shared kit in `../kit/`.
* `logic.test.mjs`: tests for the model. Run them from the repository root with `node --test 365projects/38/logic.test.mjs`.

This file is generated by `scripts/build_data.py` from `meta.json` and `data/challenge.tsv`.
