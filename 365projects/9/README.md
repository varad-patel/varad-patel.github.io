# Day 9: What Makes a Good Life? Index

Set how much you value health, freedom, income and community and get countries ranked by your own definition of a good life.

Live at https://varad-patel.github.io/365projects/9/ (part of [365 projects in 365 days](https://varad-patel.github.io/365projects/), section "Philosophy × Data").

| | |
|---|---|
| Question | Which countries offer the best life once you decide for yourself how much health, freedom, income and community matter? |
| One finding | The United States is 6th of 142 countries by income per person and 37th when health, freedom, income and community count equally. |
| Main limit | The weights are a value judgement that no data can settle, and each measure is a thin national-average proxy for the idea it stands for. |
| PPE concept | Capability approach, value pluralism |
| Skills | Index construction, normalisation |
| Data | World Happiness Report 2026, World Bank |

## Files

* `index.html`: the page, including the write-up (the idea, how it works, what it cannot tell you, extensions).
* `logic.js`: the model, with no DOM code, so it can be tested on its own.
* `app.js`: the interface, built on the shared kit in `../kit/`.
* `logic.test.mjs`: tests for the model. Run them from the repository root with `node --test 365projects/9/logic.test.mjs`.

This file is generated by `scripts/build_data.py` from `meta.json` and `data/challenge.tsv`.
