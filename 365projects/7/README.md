# Day 7: Utilitarian Calculator

Enter options, outcomes, probabilities and wellbeing weights and get an expected-utility ranking plus a chart of which weight would flip the choice.

Live at https://varad-patel.github.io/365projects/7/ (part of [365 projects in 365 days](https://varad-patel.github.io/365projects/), section "Philosophy × Data").

| | |
|---|---|
| Question | Which option produces the most expected wellbeing once every group is counted and weighted, and how far would a moral weight have to move to change the answer? |
| One finding | In the vaccine example, splitting the doses wins with 183,000 expected healthy days against 168,000 for oldest-first when everyone counts equally, but oldest-first wins once a day of an over-80's life counts for more than 1.45 times anyone else's, and care-workers-first once it counts for less than 0.58. |
| Main limit | The sum assumes wellbeing can be compared and added across people, and the moral weights that decide the ranking are ethical judgements the page cannot supply. |
| PPE concept | Utilitarianism, moral weights |
| Skills | Expected value, sensitivity analysis |
| Data | None. Everything is computed in the browser. |

## Files

* `index.html`: the page, including the write-up (the idea, how it works, what it cannot tell you, extensions).
* `logic.js`: the model, with no DOM code, so it can be tested on its own.
* `app.js`: the interface, built on the shared kit in `../kit/`.
* `logic.test.mjs`: tests for the model. Run them from the repository root with `node --test 365projects/7/logic.test.mjs`.

This file is generated by `scripts/build_data.py` from `meta.json` and `data/challenge.tsv`.
