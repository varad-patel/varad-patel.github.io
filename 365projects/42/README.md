# Day 42: Minimum Wage Simulator

Set a wage floor and pick a labour-market model (competitive or monopsony) to see effects on jobs and incomes.

Live at https://varad-patel.github.io/365projects/42/ (part of [365 projects in 365 days](https://varad-patel.github.io/365projects/), section "Economics × Data Science").

| | |
|---|---|
| Question | Does a minimum wage destroy jobs or create them, and how does the answer depend on who sets wages? |
| One finding | With the opening curves a floor of ₹160 an hour leaves 70,000 people in work under both models: 10,000 fewer than the competitive market had, and 10,000 more than the single employer had chosen to hire. |
| Main limit | The tool assumes one model or the other with made-up straight-line curves, so it cannot say which model fits a real labour market or how large the effect of a real minimum wage would be. |
| PPE concept | Labour economics |
| Skills | Model comparison |
| Data | None. Everything is computed in the browser. |

## Files

* `index.html`: the page, including the write-up (the idea, how it works, what it cannot tell you, extensions).
* `logic.js`: the model, with no DOM code, so it can be tested on its own.
* `app.js`: the interface, built on the shared kit in `../kit/`.
* `logic.test.mjs`: tests for the model. Run them from the repository root with `node --test 365projects/42/logic.test.mjs`.

This file is generated by `scripts/build_data.py` from `meta.json` and `data/challenge.tsv`.
