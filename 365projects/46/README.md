# Day 46: Income Inequality Explorer

Pick countries and see Lorenz curves and Gini over time with plain explanations.

Live at https://varad-patel.github.io/365projects/46/ (part of [365 projects in 365 days](https://varad-patel.github.io/365projects/), section "Economics × Data Science").

| | |
|---|---|
| Question | How unequal are incomes in the countries you pick, how has that changed, and how much depends on what the survey measured? |
| One finding | India's 2023 survey gives a Gini index of 23.0, the lowest latest figure of any country in the World Bank's data, but it measures consumption; in the 88 country-years where the Bank has both kinds of survey, the income index is the higher in 62, by 3.4 points on average. |
| Main limit | Household surveys miss much of the income at the very top and measure income in some countries and consumption in others, so the figures understate inequality and are not all comparable. |
| PPE concept | Inequality |
| Skills | Lorenz curve, Gini coefficient |
| Data | World Bank Poverty and Inequality Platform |
