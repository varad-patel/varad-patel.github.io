# Day 73: Central Bank Language Tracker

Paste a central bank statement and get a hawkish or dovish score against past statements.

Live at https://varad-patel.github.io/365projects/73/ (part of [365 projects in 365 days](https://varad-patel.github.io/365projects/), section "Economics × Finance").

| | |
|---|---|
| Question | How hawkish or dovish does a central bank statement read, by a published dictionary, against every FOMC statement since 2000? |
| One finding | Across 220 FOMC decisions from 2000 to 2026 the dictionary score averaged +0.34 at raises, +0.18 at holds and −0.08 at cuts, but on the 46 decisions since 2021, after the dictionary was built, it scored none of the 6 cuts below zero. |
| Main limit | A count of word pairs reads the description of the economy, not the decision or the surprise in it, and it was built from the statements it is tested on before 2021. |
| PPE concept | Monetary policy communication |
| Skills | Lexicon-based NLP |
| Data | Federal Reserve Board |

## Files

* `index.html`: the page, including the write-up (the idea, how it works, what it cannot tell you, extensions).
* `logic.js`: the model, with no DOM code, so it can be tested on its own.
* `app.js`: the interface, built on the shared kit in `../kit/`.
* `logic.test.mjs`: tests for the model. Run them from the repository root with `node --test 365projects/73/logic.test.mjs`.

This file is generated by `scripts/build_data.py` from `meta.json` and `data/challenge.tsv`.
