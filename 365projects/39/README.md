# Day 39: Demand Curve Simulator

Change price, income and preferences and watch a consumer's best basket and demand curve move.

Live at https://varad-patel.github.io/365projects/39/ (part of [365 projects in 365 days](https://varad-patel.github.io/365projects/), section "Economics × Data Science").

| | |
|---|---|
| Question | How do a consumer's best basket and demand curve move when a price, income or preferences change, and how much of the move is substitution and how much is income? |
| One finding | When the price of a good doubles from 2 to 4, a Cobb-Douglas consumer's cut from 25 to 12.5 is 7.32 substitution and 5.18 income, a quasi-linear consumer's cut is all substitution and a perfect-complements consumer's is all income. |
| Main limit | The five families of preferences are convenient shapes, not measurements of anyone's tastes, and none of them allows a good that people buy less of as they grow richer. |
| PPE concept | Consumer theory |
| Skills | Constrained optimisation |
| Data | None. Everything is computed in the browser. |

## Files

* `index.html`: the page, including the write-up (the idea, how it works, what it cannot tell you, extensions).
* `logic.js`: the model, with no DOM code, so it can be tested on its own.
* `app.js`: the interface, built on the shared kit in `../kit/`.
* `logic.test.mjs`: tests for the model. Run them from the repository root with `node --test 365projects/39/logic.test.mjs`.

This file is generated by `scripts/build_data.py` from `meta.json` and `data/challenge.tsv`.
