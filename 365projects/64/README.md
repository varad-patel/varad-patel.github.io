# Day 64: Portfolio Optimiser

Choose assets and risk tolerance and get a portfolio on the efficient frontier.

Live at https://varad-patel.github.io/365projects/64/ (part of [365 projects in 365 days](https://varad-patel.github.io/365projects/), section "Economics × Finance").

| | |
|---|---|
| Question | Which mix of assets gives the highest expected return for the volatility you accept, and how much does that mix depend on expected returns nobody knows? |
| One finding | With all eleven assets estimated over 1999 to 2026, no short positions and 4% volatility, the portfolio that is efficient on those past estimates is 59.2% 2-year Treasuries, 25.5% Australian dollar deposits and 15.3% 20-year Treasuries, but raising the 5-year Treasury's expected return by one standard error (0.82 points) moves its weight from 0% to 79.1% and changes 84.1% of the portfolio. |
| Main limit | Expected returns are past averages with standard errors of up to two percentage points a year, and the optimiser treats them as facts. |
| PPE concept | Risk and return |
| Skills | Quadratic optimisation |
| Data | Federal Reserve Board H.15 and H.10, Bank for International Settlements |
