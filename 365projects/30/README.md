# Day 30: Sunrise and Induction Calculator

Enter how often something has happened and get the probability it happens next, comparing different priors.

Live at https://varad-patel.github.io/365projects/30/ (part of [365 projects in 365 days](https://varad-patel.github.io/365projects/), section "Philosophy × Data").

| | |
|---|---|
| Question | If something has happened every time so far, how likely is it to happen next time? |
| One finding | After 1,826,213 sunrises in a row, Laplace's rule puts the odds of another at 1,826,214 to 1, Jeffreys' prior at 3,652,427 to 1 and a sceptical prior at 182,621 to 1: within 0.0006 percentage points on the probability, twentyfold apart on the chance of failure. |
| Main limit | Every number assumes the next trial is exchangeable with the ones on record, which is exactly what Hume's problem of induction calls into question. |
| PPE concept | Problem of induction |
| Skills | Beta-binomial updating |
| Data | None. Everything is computed in the browser. |
