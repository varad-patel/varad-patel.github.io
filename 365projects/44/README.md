# Day 44: Tax Systems Compared

Enter a household profile and compare what it pays under flat, progressive and consumption taxes, with India's old and new regimes as presets.

Live at https://varad-patel.github.io/365projects/44/ (part of [365 projects in 365 days](https://varad-patel.github.io/365projects/), section "Economics × Data Science").

| | |
|---|---|
| Question | What does the same household pay under a flat tax, a progressive schedule and a consumption tax, and which of India's two income-tax regimes costs it less? |
| One finding | Under India's new regime for 2026-27 a salary of ₹12.75 lakh pays no income tax and one of ₹13 lakh pays ₹26,000, more than the ₹25,000 of extra pay: from ₹12,75,000 to ₹13,45,588 the marginal rate is 104%. |
| Main limit | It is not a tax return: capital gains, the limits on each deduction and state taxes are left out, and the flat, custom and consumption taxes are not set to raise the same revenue. |
| PPE concept | Tax fairness |
| Skills | Piecewise functions |
| Data | None. Everything is computed in the browser. |

## Files

* `index.html`: the page, including the write-up (the idea, how it works, what it cannot tell you, extensions).
* `logic.js`: the model, with no DOM code, so it can be tested on its own.
* `app.js`: the interface, built on the shared kit in `../kit/`.
* `logic.test.mjs`: tests for the model. Run them from the repository root with `node --test 365projects/44/logic.test.mjs`.

This file is generated by `scripts/build_data.py` from `meta.json` and `data/challenge.tsv`.
