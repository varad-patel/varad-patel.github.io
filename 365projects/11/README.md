# Day 11: Philosophy Knowledge Graph

Search any thinker and explore an interactive influence graph with the most central philosophers ranked.

Live at https://varad-patel.github.io/365projects/11/ (part of [365 projects in 365 days](https://varad-patel.github.io/365projects/), section "Philosophy × Data").

| | |
|---|---|
| Question | Who sits at the centre of the web of philosophical influence, and how is any one thinker connected to the rest? |
| One finding | Kant has the most recorded followers (79), but PageRank puts Plato first and lifts Heraclitus from joint 30th by follower count to 5th. |
| Main limit | The graph is Wikidata's volunteer-written record of influence, which is incomplete, leans European and says nothing about the strength or kind of each link. |
| PPE concept | History of ideas |
| Skills | Wikidata snapshot, PageRank, graph visualisation |
| Data | Wikidata |

## Files

* `index.html`: the page, including the write-up (the idea, how it works, what it cannot tell you, extensions).
* `logic.js`: the model, with no DOM code, so it can be tested on its own.
* `app.js`: the interface, built on the shared kit in `../kit/`.
* `logic.test.mjs`: tests for the model. Run them from the repository root with `node --test 365projects/11/logic.test.mjs`.

This file is generated by `scripts/build_data.py` from `meta.json` and `data/challenge.tsv`.
