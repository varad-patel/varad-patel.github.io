# Day 5: Zeno's Series Calculator

Set the tortoise's head start and both speeds and watch the chase animate while partial sums close in on the catch-up point.

Live at https://varad-patel.github.io/365projects/5/ (part of [365 projects in 365 days](https://varad-patel.github.io/365projects/), section "Philosophy × Data").

| | |
|---|---|
| Question | If Achilles must first reach where the tortoise was, infinitely many times over, how far and how long does the chase actually take? |
| One finding | With a 100 m head start at 10 m/s against 5 m/s, the tortoise still leads by 9.8 cm after 10 of Zeno's stages and by under a millimetre after 17, no stage closes the gap, and yet all infinitely many stages are over within 200 m and 20 seconds. |
| Main limit | A convergent series shows that the stages fit into a finite time, not what it means to complete infinitely many acts or whether real space and time divide without end. |
| PPE concept | Zeno's paradoxes, infinity |
| Skills | Geometric series, limits, canvas animation |
| Data | None. Everything is computed in the browser. |

## Files

* `index.html`: the page, including the write-up (the idea, how it works, what it cannot tell you, extensions).
* `logic.js`: the model, with no DOM code, so it can be tested on its own.
* `app.js`: the interface, built on the shared kit in `../kit/`.
* `logic.test.mjs`: tests for the model. Run them from the repository root with `node --test 365projects/5/logic.test.mjs`.
