# Day 118: Regression to the Mean Simulator

Pick a scenario such as 'the worst performers improve' and see the effect appear with no cause at all.

Live at https://varad-patel.github.io/365projects/118/ (part of [365 projects in 365 days](https://varad-patel.github.io/365projects/), section "Knowledge, Logic and Uncertainty").

| | |
|---|---|
| Question | Why does a group picked for being extreme look better or worse the next time it is measured, even when nothing has been done to it? |
| One finding | In Galton's records the 94 children whose mid-parents were in the tallest tenth were 2.5 inches above average against their mid-parents' 3.3, and the tallest tenth of children had mid-parents only 2.0 inches above average against their own 4.3: the pull towards the mean runs both ways, so it cannot be caused by the parents. |
| Main limit | The simulated scenarios use illustrative correlations, and the amount of regression in a real case depends on a correlation that has to be measured. |
| PPE concept | Causal reasoning |
| Skills | Simulation, correlation |
| Data | Galton height data (Harvard Dataverse) |
