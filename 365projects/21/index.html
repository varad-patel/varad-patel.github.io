Liar Paradox Evaluator

Write sentences that talk about their own truth and each other's. Three theories of truth then try to give each one a value, and you can watch where they succeed, where they loop and where they disagree.

One finding

A ring of sentences, each saying that the next one is false, is paradoxical exactly when the ring is odd. With 1, 3, 5 or 7 sentences no assignment of true and false is consistent and every sentence loops from every starting guess. With 2, 4, 6 or 8 exactly two assignments are consistent, yet revision finds them only if it starts on one: from 2 of the 256 guesses for a ring of eight.

The idea

"This sentence is false." If it is true, then what it says holds, so it is false. If it is false, then what it says fails, so it is true. The puzzle is credited to Eubulides in the fourth century BC and has never gone away, because it uses nothing exotic: a sentence, the word "false", and the ability of a sentence to refer to itself. None of the three is easy to give up.

Alfred Tarski's response in the 1930s was to forbid the combination. A language may not contain its own truth predicate; "true in L" belongs to a richer language one level up, and so on in a hierarchy. That blocks the Liar, at the price of ruling out harmless sentences such as "everything in this paragraph is true". In 1975 Saul Kripke showed that a language can contain its own truth predicate if some sentences are allowed to have no truth value. Sentences whose truth traces back to facts that are not about truth are grounded; the Liar is not, and gets nothing. Kripke also stressed that whether a sentence is paradoxical can depend on the facts and not on its form: his example is a claim that most of Nixon's assertions about Watergate are false, which is harmless or paradoxical depending on what else was said.

Anil Gupta, Hans Herzberger and Nuel Belnap took a different line in the 1980s. Treat the definition of truth as a rule for improving a guess: start with any assignment of truth values, re-evaluate every sentence against it, and repeat. Ordinary sentences settle down whatever you start with. The Liar flips for ever, and the theory takes that instability as its description of the sentence, not as a failure to give one.

The same structure turns up wherever a system can describe itself: a spreadsheet cell that depends on its own value, a rule that governs its own amendment, and the self-referring sentence at the centre of Gödel's incompleteness theorem (day 22), which swaps "false" for "unprovable" and gets a theorem where the Liar gets a paradox.

How it works

The language

Each line defines one sentence as Name: formula; a line with no name is given the next free letter. A formula is built from these pieces:

  • X is true and X is false, where X is a name or this sentence. A bare name means "X is true". X is not true is read as X is false, and X is not false as X is true: the language has no way to say that a sentence lacks a value.
  • a plain fact written as a sum: 2 + 2 = 4, 3 * 4 < 10, with +, −, × (or *), and =, ≠, <, >, ≤, ≥ on whole numbers. Sums are worked out exactly, and one whose numbers pass 253 is refused;
  • not, and, or, if … then … (or implies), iff (or if and only if), and brackets. The symbols ~ & | -> <-> work too. "Not" binds tightest, then "and", "or", the conditional and "iff".

Names ignore capitals and can have up to 20 characters. Commas, and a full stop at the end, are ignored. A sentence may hold at most 200 words and symbols.

Write φX for the formula that defines sentence X, and ⟦φ⟧v for its value when every "Y is true" inside it is given the value v(Y). All three methods are ways of looking for a v that the definitions agree with.

1. Classical consistency

Give every sentence the value true or false. The assignment is consistent when each sentence comes out with the value it was given:

v(X) = ⟦φX⟧v   for every sentence X

With n sentences there are 2n assignments, and the tool tries them all. None consistent means the definitions cannot be satisfied, as with the Liar. Exactly one means every sentence is determinate. Several means the definitions leave the matter open, as with the Truth-teller, "this sentence is true", which is consistent both ways. For each sentence the tool repeats the count on just the sentences it depends on, so that a Liar elsewhere on the page does not condemn a sentence that never mentions it.

2. Kripke's least fixed point

Now allow a third state, no value, and use the strong Kleene rules for the connectives: "not" swaps true and false and leaves a gap a gap; "and" is false as soon as one side is false, true when both are true, and otherwise has no value; "or" is the mirror image; "if a then b" is "(not a) or b". Coding true as 1, false as 0 and no value as ½, these are 1 − a, min(a, b) and max(a, b).

Start at stage 0 with no sentence having a value. At each stage, evaluate every sentence against the stage before:

vk+1(X) = ⟦φX⟧vk

A sum is true or false at stage 1. A sentence about a sum gets its value at stage 2, and so on. Because the Kleene rules never withdraw a value when a gap is filled in, values are only ever added, and with n sentences the process stops within n stages. The result is the least fixed point: sentences with a value there are grounded, the rest are ungrounded.

The least fixed point is not the only one. Any assignment of true, false or gap that satisfies the equation above is a fixed point, and the tool finds them all by trying every value for the ungrounded sentences. The Truth-teller has three (true, false, gap). The Liar has one (gap). Following Kripke, a sentence that receives true or false in no fixed point at all is called paradoxical; one that is merely ungrounded could be given a value without contradiction, though nothing forces which.

3. Revision sequences

Go back to two values, but stop asking for consistency. Take any guess h0 and revise it with the same equation, read classically:

hk+1(X) = ⟦φX⟧hk

There are only 2n possible guesses, so the sequence must come back to one it has already visited and then repeat for ever. If the repeating part is a single stage, the sequence has reached a consistent assignment. If it is longer, some sentences keep changing. A sentence settles from a given guess when it has the same value all the way round the loop. The panel shows the sequence from the guess you choose; the verdict runs all 2n guesses.

The call

The label on each sentence comes from the revision over every guess: true or false if the sentence settles on that value whatever the guess, looping if it never settles from any guess, and unsettled if the outcome depends on the guess. The other two verdicts are printed beside it because they can differ.

How the three fit together

A consistent classical assignment is exactly a guess that revision leaves unchanged, and exactly a fixed point with no gaps. A grounded sentence has its grounded value in every consistent assignment and settles on it from every guess within n stages. The tests check both statements on 300 random systems of five sentences. Outside the grounded sentences the methods come apart: "A: A is true and A is false" is ungrounded for Kripke and plainly false for the other two, and a true sentence that happens to mention a Liar is grounded and stable but has no consistent classical assignment.

What this cannot tell you

  • Which theory of truth is right. The three methods are rival accounts of what "true" means for sentences like these. The tool runs each faithfully on a small language; it does not adjudicate, and the single-word call is a convenience that takes one side.
  • How to escape the revenge problem. The language cannot say "this sentence has no value" or "this sentence loops". If it could, that sentence would be a new Liar about the evaluator itself. Here "is not true" is read as "is false", which avoids the question and does not answer it. Kripke's own remark was that the ghost of the Tarski hierarchy is still with us.
  • What happens beyond the finite stages. The full revision theory carries sequences on through infinite stages, with a rule for what to keep at each limit. This page reads its verdict off the finite loop. The two can differ: in "A: A is false; B: A is true; S: A is true iff B is false", S is true from stage 2 on from every guess, because from stage 1 on A and B disagree. At the first infinite stage Herzberger's rule keeps what has settled and makes every unsettled sentence false, so A and B are both false there, and S is false at the stage after. Under that rule S never settles; this page calls it true.
  • Anything about infinitely many sentences. There are no quantifiers, so "everything I say is false" and Yablo's paradox, an endless list in which each sentence says that all later ones are untrue, cannot be written. The limit of ten sentences is practical: the tool enumerates every assignment.
  • What other gap logics would say. Only the strong Kleene scheme is implemented. Under supervaluation "A: A is true or A is false" would be grounded true; here it is ungrounded.
  • Whether a real sentence is paradoxical. The only facts available are sums. Kripke's point that paradox can turn on empirical facts can be imitated by editing a sum from true to false, but ordinary English sentences have to be translated by hand, and the translation is where the judgement lies.

Improvements and extensions

  • Add the weak Kleene and supervaluation schemes next to strong Kleene, and show which sentences each one grounds.
  • Continue revision into the transfinite with a choice of limit rule (Herzberger's, Gupta's, Belnap's) and report where the verdict changes.
  • Draw the reference graph: who mentions whom, with each cycle marked by whether it contains an odd number of negations.
  • Add quantifiers over the sentences on the page ("exactly one of these is true") so that knights-and-knaves puzzles and truncated Yablo sequences can be typed.
  • Let plain facts be switches, so that a sentence can be watched moving from grounded to paradoxical as the facts change.
  • Compute the largest intrinsic fixed point, Kripke's candidate for the values that are forced without being arbitrary.
