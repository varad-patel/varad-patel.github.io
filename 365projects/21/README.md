# Day 21: Liar Paradox Evaluator

Type self-referential sentences and see which the evaluator calls true, false or looping.

Live at https://varad-patel.github.io/365projects/21/ (part of [365 projects in 365 days](https://varad-patel.github.io/365projects/), section "Philosophy × Data").

| | |
|---|---|
| Question | When sentences talk about their own truth and each other's, which of them come out true, which false, and which can never settle? |
| One finding | A ring of sentences that each call the next one false is paradoxical exactly when the ring is odd: 0 consistent assignments for 1, 3, 5 and 7 sentences, exactly 2 for 2, 4, 6 and 8, which revision reaches from only 2 of the 256 starting guesses for a ring of eight. |
| Main limit | The three methods are rival theories of truth run on a ten-sentence toy language with finite revision stages only, so the tool shows what each theory says and cannot settle which is right. |
| PPE concept | Truth and self-reference |
| Skills | Recursion, fixed points |
| Data | None. Everything is computed in the browser. |

## Files

* `index.html`: the page, including the write-up (the idea, how it works, what it cannot tell you, extensions).
* `logic.js`: the model, with no DOM code, so it can be tested on its own.
* `app.js`: the interface, built on the shared kit in `../kit/`.
* `logic.test.mjs`: tests for the model. Run them from the repository root with `node --test 365projects/21/logic.test.mjs`.

This file is generated by `scripts/build_data.py` from `meta.json` and `data/challenge.tsv`.
