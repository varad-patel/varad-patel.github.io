# Day 62: Random Walk versus Reality

Choose any stock or index from a built-in list and get a verdict on whether its price behaves like a random walk.

Live at https://varad-patel.github.io/365projects/62/ (part of [365 projects in 365 days](https://varad-patel.github.io/365projects/), section "Economics × Finance").

| | |
|---|---|
| Question | Does the price of a stock index move like a random walk? |
| One finding | For the S&P/TSX Composite over 812 monthly changes from 1956 to 2023 the two-month variance ratio is 1.095 and would look significant on its own (p = 0.031), but the joint test across four horizons finds it consistent with a random walk (p = 0.120), and of the 21 indices in the list 4 reject at the 5% level and none after allowing for 21 tests. |
| Main limit | Failing to reject a random walk is not proof of one, and no individual share prices could be republished, so the verdicts are about Canadian indices only. |
| PPE concept | Efficient market hypothesis |
| Skills | Variance-ratio tests |
| Data | Statistics Canada |
