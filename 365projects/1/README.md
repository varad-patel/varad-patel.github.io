# Day 1: Can Money Buy Happiness?

Pick countries and controls (health, freedom, social support) and see how much income explains life satisfaction, with a fitted line and clickable outliers.

Live at https://varad-patel.github.io/365projects/1/ (part of [365 projects in 365 days](https://varad-patel.github.io/365projects/), section "Philosophy × Data").

| | |
|---|---|
| Question | How much of the link between national income and life satisfaction is left once health, freedom and social support are held fixed? |
| One finding | Across 142 countries in 2023 to 2025, income alone accounts for 63% of the differences in life evaluation, but less than one percentage point is unique to income once five other factors are held fixed. |
| Main limit | A cross-section of country averages cannot show that money causes happiness, and it says nothing about individuals inside a country. |
| PPE concept | Wellbeing and income |
| Skills | Multiple regression, log transforms, JavaScript charts |
| Data | World Happiness Report 2026, World Bank |

## Files

* `index.html`: the page, including the write-up (the idea, how it works, what it cannot tell you, extensions).
* `logic.js`: the model, with no DOM code, so it can be tested on its own.
* `app.js`: the interface, built on the shared kit in `../kit/`.
* `logic.test.mjs`: tests for the model. Run them from the repository root with `node --test 365projects/1/logic.test.mjs`.

This file is generated by `scripts/build_data.py` from `meta.json` and `data/challenge.tsv`.
