# Day 4: Bayes Intuition Lab

Move prior, sensitivity and false-positive sliders for a medical test and see the posterior update as natural-frequency pictures.

Live at https://varad-patel.github.io/365projects/4/ (part of [365 projects in 365 days](https://varad-patel.github.io/365projects/), section "Philosophy × Data").

| | |
|---|---|
| Question | If a medical test comes back positive, how likely is it that the person actually has the condition? |
| One finding | With a 1% base rate, 80% sensitivity and a 9.6% false-positive rate, a positive result means a 7.8% chance of the condition: of 1,000 people tested, 103 test positive and only 8 of them have it. |
| Main limit | The scenarios use textbook or illustrative numbers and a single yes/no test, so the page explains how to read a test result and cannot interpret a real one. |
| PPE concept | Epistemology, base-rate neglect |
| Skills | Bayes' theorem, live visualisation |
| Data | None. Everything is computed in the browser. |

## Files

* `index.html`: the page, including the write-up (the idea, how it works, what it cannot tell you, extensions).
* `logic.js`: the model, with no DOM code, so it can be tested on its own.
* `app.js`: the interface, built on the shared kit in `../kit/`.
* `logic.test.mjs`: tests for the model. Run them from the repository root with `node --test 365projects/4/logic.test.mjs`.

This file is generated by `scripts/build_data.py` from `meta.json` and `data/challenge.tsv`.
