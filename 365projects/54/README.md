# Day 54: The Education Premium

Enter your education and profile and see expected earnings gains with uncertainty.

Live at https://varad-patel.github.io/365projects/54/ (part of [365 projects in 365 days](https://varad-patel.github.io/365projects/), section "Economics × Data Science").

| | |
|---|---|
| Question | How much more are people with more education paid in the United States, and how much does that average say about one person? |
| One finding | For a woman of 35 working full time in the United States in 2024, the central estimate of pay is $40,900 with a high school diploma and $72,100 with a bachelor's degree, 76% more (95% interval 75% to 77%), yet 21% of the time a woman of 35 to 44 with only the diploma is paid more than one with the degree. |
| Main limit | The gap compares different people, so it is not what a qualification would add for any one person, and it counts neither the cost of studying nor anyone who is not a full-time, year-round employee. |
| PPE concept | Human capital |
| Skills | Mincer regression |
| Data | US Census Bureau, American Community Survey 2024 (Public Use Microdata Sample), Montenegro and Patrinos (2014), World Bank |

## Files

* `index.html`: the page, including the write-up (the idea, how it works, what it cannot tell you, extensions).
* `logic.js`: the model, with no DOM code, so it can be tested on its own.
* `app.js`: the interface, built on the shared kit in `../kit/`.
* `logic.test.mjs`: tests for the model. Run them from the repository root with `node --test 365projects/54/logic.test.mjs`.

This file is generated by `scripts/build_data.py` from `meta.json` and `data/challenge.tsv`.
