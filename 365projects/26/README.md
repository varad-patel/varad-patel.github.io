# Day 26: Nature versus Nurture Simulator

Set gene and environment parameters and see simulated traits and the heritability estimate.

Live at https://varad-patel.github.io/365projects/26/ (part of [365 projects in 365 days](https://varad-patel.github.io/365projects/), section "Philosophy × Data").

| | |
|---|---|
| Question | What does a heritability estimate actually measure, and what changes it? |
| One finding | With genetic variance held at 50, heritability is 0.50, 0.91 or 0.20 depending only on how much environments differ, and a simulated study of 500 twin pairs of each kind estimates the first as 0.57 with a 95% interval from 0.40 to 0.73. |
| Main limit | Every variance is a setting, so the page shows what follows from assumptions about a population and says nothing about any real trait, any one person, or why groups differ. |
| PPE concept | Nature versus nurture, determinism |
| Skills | Variance decomposition, simulation |
| Data | None. Everything is computed in the browser. |

## Files

* `index.html`: the page, including the write-up (the idea, how it works, what it cannot tell you, extensions).
* `logic.js`: the model, with no DOM code, so it can be tested on its own.
* `app.js`: the interface, built on the shared kit in `../kit/`.
* `logic.test.mjs`: tests for the model. Run them from the repository root with `node --test 365projects/26/logic.test.mjs`.

This file is generated by `scripts/build_data.py` from `meta.json` and `data/challenge.tsv`.
