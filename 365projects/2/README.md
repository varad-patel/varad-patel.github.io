# Day 2: Truth Table Playground

Type any logical formula and get its truth table, a tautology or contradiction verdict and a step-by-step evaluation.

Live at https://varad-patel.github.io/365projects/2/ (part of [365 projects in 365 days](https://varad-patel.github.io/365projects/), section "Philosophy × Data").

| | |
|---|---|
| Question | In which situations is a formula true, and does an argument's conclusion really follow from its premises? |
| One finding | Affirming the consequent (if p then q; q; therefore p) is invalid because of exactly one of its four rows: p false and q true. |
| Main limit | A truth table checks the form of an argument, not whether its premises are true or whether the English was translated into symbols correctly. |
| PPE concept | Propositional logic, validity |
| Skills | Boolean algebra, parsing, JavaScript |
| Data | None. Everything is computed in the browser. |

## Files

* `index.html`: the page, including the write-up (the idea, how it works, what it cannot tell you, extensions).
* `logic.js`: the model, with no DOM code, so it can be tested on its own.
* `app.js`: the interface, built on the shared kit in `../kit/`.
* `logic.test.mjs`: tests for the model. Run them from the repository root with `node --test 365projects/2/logic.test.mjs`.

This file is generated by `scripts/build_data.py` from `meta.json` and `data/challenge.tsv`.
