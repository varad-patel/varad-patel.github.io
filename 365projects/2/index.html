Truth Table Playground

Type any formula of propositional logic and see every case it could face: its full truth table, a verdict, and any row worked out step by step.

One finding

Affirming the consequent ("if p then q; q; therefore p") is invalid because of exactly one of its four rows: p false and q true. Modus ponens differs by one letter and has no such row. One row is all it takes to sink an argument, and no number of agreeable rows can save it.

The idea

An argument is valid when its conclusion cannot be false while its premises are true. That is a claim about every possible situation, which sounds impossible to check. Propositional logic makes it checkable by a simple observation: if the only thing that matters about each basic statement is whether it is true or false, then a formula with n letters faces exactly 2n situations, and you can list them all.

The list is a truth table. Wittgenstein used them in the Tractatus and Emil Post published the method in the same year, 1921. A formula that comes out true in every row is a tautology: true whatever the world is like, and for that reason it tells you nothing about the world. One that is false in every row is a contradiction. Everything else is contingent.

This matters outside a logic class because validity is about form, not subject matter. "If the minimum wage rises, unemployment rises; unemployment rose; so the minimum wage must have risen" has the same shape as the example in the box above, and it fails for the same reason, whatever you believe about wages. Being able to separate the shape of an argument from its topic is the first tool of philosophy, and it is the one that politics most often does without.

How it works

Reading the formula

The text is split into tokens (letters, connectives, brackets, commas), then parsed by recursive descent, with one function for each level of binding strength. From tightest to loosest:

¬  then  ∧, ↑  then  ⊕  then  ∨, ↓  then  →  then  ↔

So ¬p ∧ q → r is read as ((¬p) ∧ q) → r. The conditional groups to the right (p → q → r is p → (q → r)); the others group to the left. The result is a tree, and the page prints it back with only the brackets it needs, so you can check it understood you.

The connectives

Each connective is a function from truth values to a truth value. The one that surprises people is the conditional: p → q is false in exactly one case, when p is true and q is false, and true in the other three.

p → q  =  ¬p ∨ q      p ↔ q  =  (p → q) ∧ (q → p)      p ⊕ q  =  ¬(p ↔ q)

Building the table

With n distinct letters there are 2n rows, one for each assignment of true and false. For each row the page evaluates the tree from the leaves up, and gives every compound subformula its own column, innermost first. The step-by-step panel is the same calculation for a single row, written out.

The verdicts

  • One formula. True in all rows: tautology. In none: contradiction. Otherwise contingent, with the count.
  • An argument (premises ⊢ conclusion). The page looks for a row where every premise is true and the conclusion is false. If there is none, the argument is valid. If there is one, that row is a counterexample, and it is highlighted.
  • Several formulas. Two formulas are logically equivalent when their columns agree in every row. The page checks each pair.

Normal forms

Any truth table can be written as a formula using only ¬, ∧ and ∨. Take each row where the formula is true, write the conjunction that describes that row exactly, and join them with ∨: that is the disjunctive normal form. The conjunctive form does the mirror image with the false rows. This is the proof that those three connectives are enough to express every truth function.

What this cannot tell you

  • Whether an argument is sound. Validity only says the conclusion follows. A valid argument with a false premise proves nothing, and the table has no opinion about which premises are true.
  • Whether your translation is right. Turning an English sentence into letters and arrows is where most of the judgement lies. The page checks the formula you typed, not the sentence you meant.
  • What "if" means in English. The arrow here is the material conditional, true whenever its first part is false. So "if the moon is cheese, then 2 + 2 = 5" counts as true. Ordinary conditionals carry a connection between the two parts that this logic deliberately ignores.
  • Anything inside a statement. "All humans are mortal; Socrates is human; so Socrates is mortal" is valid, but as p, q ⊢ r it looks invalid, because the logic cannot see "all" or "is". That takes predicate logic, which has no finite table.
  • Anything that is not simply true or false. Vague statements, statements about what must or might be the case, and statements about the future may need more than two values, or a different logic altogether.
  • Large problems. The table doubles with every letter, which is why the page stops at ten. Deciding whether a formula can be true at all is the original NP-complete problem; real solvers avoid listing the rows.

Improvements and extensions

  • Simplify the normal forms to their shortest equivalent (the Quine-McCluskey method), so the page can answer "what is the simplest way to say this?"
  • Give a natural-deduction proof for valid arguments, so a visitor sees why it holds and not only that it does.
  • Replace the brute-force table with a satisfiability solver for formulas with dozens of letters. Day 142 builds one.
  • Add three-valued tables (true, false, undefined) to show what changes when the two-value assumption is dropped. Day 21 needs them for the Liar.
  • Put the formula in the page address so a table can be shared as a link.
