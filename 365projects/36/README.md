# Day 36: House Price Predictor

Enter a property and get a price estimate plus what each feature adds to it.

Live at https://varad-patel.github.io/365projects/36/ (part of [365 projects in 365 days](https://varad-patel.github.io/365projects/), section "Economics × Data Science").

| | |
|---|---|
| Question | What does each feature of a flat add to its price, and how close can a regression on recorded sales get to the price paid? |
| One finding | The same 42 m² two-room flat is estimated at €578,000 in the 6th arrondissement of Paris and €338,000 in the 19th, 71% more for the address alone, and on 28,445 held-out sales half of the model's estimates were within 12.8% of the price paid. |
| Main limit | The model knows only flats sold in Paris from 2021 to 2025 and sees nothing of a flat's floor, condition or street, so it is not a valuation of any home. |
| PPE concept | Hedonic pricing |
| Skills | Hedonic regression |
| Data | DGFiP Demandes de valeurs foncières |

## Files

* `index.html`: the page, including the write-up (the idea, how it works, what it cannot tell you, extensions).
* `logic.js`: the model, with no DOM code, so it can be tested on its own.
* `app.js`: the interface, built on the shared kit in `../kit/`.
* `logic.test.mjs`: tests for the model. Run them from the repository root with `node --test 365projects/36/logic.test.mjs`.

This file is generated by `scripts/build_data.py` from `meta.json` and `data/challenge.tsv`.
