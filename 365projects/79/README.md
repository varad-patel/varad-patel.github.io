# Day 79: Sovereign Default Simulator

Set debt levels and shocks and see when a government would rationally default.

Live at https://varad-patel.github.io/365projects/79/ (part of [365 projects in 365 days](https://varad-patel.github.io/365projects/), section "Economics × Finance").

| | |
|---|---|
| Question | When would a government that weighs the costs of default against the costs of repaying choose not to pay its foreign debt? |
| One finding | With Arellano's numbers for Argentina, a government at trend income repays debts up to 2.44% of a year's income and defaults on 2.50% or more, but 2.3% below trend it defaults on 1.25%; in one simulated history of 50,000 years it defaults 3.4 times a century (other seeds give up to 3.6), 98% of those defaults with income below trend, on average 8.2% below. |
| Main limit | The penalties for default are assumed rather than derived, debt is one-quarter bonds held by risk-neutral lenders, and the model supports far less debt than real governments owe. |
| PPE concept | Sovereign debt |
| Skills | Dynamic optimisation |
| Data | None. Everything is computed in the browser. |

## Files

* `index.html`: the page, including the write-up (the idea, how it works, what it cannot tell you, extensions).
* `logic.js`: the model, with no DOM code, so it can be tested on its own.
* `app.js`: the interface, built on the shared kit in `../kit/`.
* `logic.test.mjs`: tests for the model. Run them from the repository root with `node --test 365projects/79/logic.test.mjs`.
