# Day 18: Newcomb's Problem Calculator

Set the predictor's accuracy and the payoffs and find where one-boxing beats two-boxing.

Live at https://varad-patel.github.io/365projects/18/ (part of [365 projects in 365 days](https://varad-patel.github.io/365projects/), section "Philosophy × Data").

| | |
|---|---|
| Question | How accurate does the predictor have to be before taking one box has a higher expected value than taking both, and why does that not settle what to do? |
| One finding | With a million in the opaque box and a thousand in the clear one, one-boxing has the higher evidential expected value once the predictor is right more than 50.05% of the time, yet in every one of 100,000 simulated plays taking both boxes would have paid exactly $1,000 more. |
| Main limit | Both calculations are correct arithmetic, so the page cannot say which is the rational choice: the disagreement is over which probabilities belong in the sum. |
| PPE concept | Causal versus evidential decision theory |
| Skills | Expected value |
| Data | None. Everything is computed in the browser. |
