# Day 66: Black-Scholes Playground

Set an option's inputs and see its price, Greeks and payoff diagram update live.

Live at https://varad-patel.github.io/365projects/66/ (part of [365 projects in 365 days](https://varad-patel.github.io/365projects/), section "Economics × Finance").

| | |
|---|---|
| Question | What is an option worth under the Black-Scholes-Merton model, and how do its price and Greeks move as the share price, time, volatility and interest change? |
| One finding | An at-the-money one-year call on a $100 share (20% volatility, 5% interest) is worth $10.45 and loses 1.8 cents a day; with a week left it is worth $1.15 and loses 8.6 cents a day, and with a day left 21.6 cents, while its gamma rises twentyfold from 0.019 to 0.38. |
| Main limit | The model takes volatility as known and constant and prices move without jumps, so real option prices, which imply different volatilities at different strikes, depart from it most for large moves. |
| PPE concept | Pricing uncertainty |
| Skills | Closed-form pricing |
| Data | None. Everything is computed in the browser. |

## Files

* `index.html`: the page, including the write-up (the idea, how it works, what it cannot tell you, extensions).
* `logic.js`: the model, with no DOM code, so it can be tested on its own.
* `app.js`: the interface, built on the shared kit in `../kit/`.
* `logic.test.mjs`: tests for the model. Run them from the repository root with `node --test 365projects/66/logic.test.mjs`.

This file is generated by `scripts/build_data.py` from `meta.json` and `data/challenge.tsv`.
