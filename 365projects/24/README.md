# Day 24: Personal Forecast Log

Log predictions with probabilities, resolve them later and see your scorecard build. Built early so that a year of forecasts exists by the Forecasting League on Day 314.

Live at https://varad-patel.github.io/365projects/24/ (part of [365 projects in 365 days](https://varad-patel.github.io/365projects/), section "Philosophy × Data").

| | |
|---|---|
| Question | When you say you are 80% sure, are you right 80% of the time? |
| One finding | A forecaster who says 90% every time and is right 70% of the time scores exactly 0.25, the same as answering 50% to everything; that is a property of the Brier score, and the made-up example log (80% confident, 71% right over 24 predictions, score 0.216) only illustrates it. |
| Main limit | The score depends on which questions you choose and on your own honesty in resolving them, and a few dozen forecasts are too few to separate skill from luck. |
| PPE concept | Forecasting |
| Skills | Brier score, local storage |
| Data | None. Everything is computed in the browser. |

## Files

* `index.html`: the page, including the write-up (the idea, how it works, what it cannot tell you, extensions).
* `logic.js`: the model, with no DOM code, so it can be tested on its own.
* `app.js`: the interface, built on the shared kit in `../kit/`.
* `logic.test.mjs`: tests for the model. Run them from the repository root with `node --test 365projects/24/logic.test.mjs`.

This file is generated by `scripts/build_data.py` from `meta.json` and `data/challenge.tsv`.
