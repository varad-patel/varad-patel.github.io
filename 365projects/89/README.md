# Day 89: Voting Method Comparer

Rank candidates on a shared ballot and see how plurality, ranked choice, approval and Borda give different winners.

Live at https://varad-patel.github.io/365projects/89/ (part of [365 projects in 365 days](https://varad-patel.github.io/365projects/), section "Politics × Data").

| | |
|---|---|
| Question | When the same voters rank the same candidates, how often do plurality, runoffs, approval, Borda and Condorcet's methods elect different winners? |
| One finding | On Pacuit's 21 voters plurality elects A, the runoffs, approval and Borda elect B, and Copeland and Schulze elect C; across 1,000 simulated three-candidate elections of 101 voters under impartial culture a Condorcet winner existed in 91.5%, plurality elected it 73.2% of the time against 95.6% for instant runoff, and all seven methods agreed in 52.4%. |
| Main limit | Every ballot is assumed sincere and complete, and the simulated electorates come from simple models, not real elections. |
| PPE concept | Social choice |
| Skills | Voting algorithms, simulation |
| Data | None. Everything is computed in the browser. |
