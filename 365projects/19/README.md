# Day 19: Sleeping Beauty Simulator

Run the experiment live and see how 'halfer' and 'thirder' answers come from counting different things.

Live at https://varad-patel.github.io/365projects/19/ (part of [365 projects in 365 days](https://varad-patel.github.io/365projects/), section "Philosophy × Data").

| | |
|---|---|
| Question | Where do the halfer's 1/2 and the thirder's 1/3 come from when the same Sleeping Beauty experiment is run thousands of times? |
| One finding | In 101,000 simulated experiments the coin landed heads in 50.03% of experiments but only 33.36% of awakenings came after heads, and a ticket on heads priced at 0.40 made 0.10 per experiment sold once per experiment and lost 0.10 per experiment sold at every awakening. |
| Main limit | The simulation shows what each position counts, not which count Beauty's credence should follow. |
| PPE concept | Self-locating belief |
| Skills | Conditional probability, simulation |
| Data | None. Everything is computed in the browser. |

## Files

* `index.html`: the page, including the write-up (the idea, how it works, what it cannot tell you, extensions).
* `logic.js`: the model, with no DOM code, so it can be tested on its own.
* `app.js`: the interface, built on the shared kit in `../kit/`.
* `logic.test.mjs`: tests for the model. Run them from the repository root with `node --test 365projects/19/logic.test.mjs`.

This file is generated by `scripts/build_data.py` from `meta.json` and `data/challenge.tsv`.
