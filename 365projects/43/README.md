# Day 43: Basic Income Microsimulation

Set a basic income and tax schedule and see cost, poverty rate and winners and losers across a synthetic population.

Live at https://varad-patel.github.io/365projects/43/ (part of [365 projects in 365 days](https://varad-patel.github.io/365projects/), section "Economics × Data Science").

| | |
|---|---|
| Question | What would a basic income cost, who would gain and lose, and what tax rates would pay for it? |
| One finding | In a simulated population of 20,000 households, ₹6,000 a month for every adult and ₹3,000 for every child needs 16.6 points on both rates of income tax to pay for itself, halves poverty from 23.4% to 11.2%, and leaves 63.7% of people better off and 36.3% worse off. |
| Main limit | The households are invented and nobody changes how much they work or earn, so the figures show how the arithmetic of a basic income works, not what one would do in a real country. |
| PPE concept | Welfare policy |
| Skills | Microsimulation |
| Data | None. Everything is computed in the browser. |

## Files

* `index.html`: the page, including the write-up (the idea, how it works, what it cannot tell you, extensions).
* `logic.js`: the model, with no DOM code, so it can be tested on its own.
* `app.js`: the interface, built on the shared kit in `../kit/`.
* `logic.test.mjs`: tests for the model. Run them from the repository root with `node --test 365projects/43/logic.test.mjs`.

This file is generated by `scripts/build_data.py` from `meta.json` and `data/challenge.tsv`.
