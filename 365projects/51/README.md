# Day 51: Cartel Stability Simulator

Set patience, number of firms and punishment and see whether the cartel holds together.

Live at https://varad-patel.github.io/365projects/51/ (part of [365 projects in 365 days](https://varad-patel.github.io/365projects/), section "Economics × Data Science").

| | |
|---|---|
| Question | How patient must the members of a cartel be for the agreement to hold, given how many they are and how cheating is punished? |
| One finding | With permanent punishment and prompt detection, two firms need a discount factor of 0.500 if they would otherwise compete on price and 0.529 on quantity, and ten firms need 0.900 and 0.752; a two-period price war raises the two-firm figures to 0.618 and 0.673, and a one-period war holds no cartel together at any patience. |
| Main limit | Cheating is always detected and the market never changes, so the model leaves out the imperfect monitoring, demand swings, entry and bargaining that break most real cartels. |
| PPE concept | Collusion, repeated games |
| Skills | Folk theorem |
| Data | None. Everything is computed in the browser. |

## Files

* `index.html`: the page, including the write-up (the idea, how it works, what it cannot tell you, extensions).
* `logic.js`: the model, with no DOM code, so it can be tested on its own.
* `app.js`: the interface, built on the shared kit in `../kit/`.
* `logic.test.mjs`: tests for the model. Run them from the repository root with `node --test 365projects/51/logic.test.mjs`.

This file is generated by `scripts/build_data.py` from `meta.json` and `data/challenge.tsv`.
