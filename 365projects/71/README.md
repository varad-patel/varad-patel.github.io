# Day 71: News and Markets Event Study

Choose a dated event and see abnormal returns around it.

Live at https://varad-patel.github.io/365projects/71/ (part of [365 projects in 365 days](https://varad-patel.github.io/365projects/), section "Economics × Finance").

| | |
|---|---|
| Question | How far did a currency move around a piece of news beyond what the rest of the market explains? |
| One finding | Over the two days after Draghi's "whatever it takes" the euro rose 1.9% against the dollar, but the basket of other currencies (without the krone and the franc, then both tied to the euro) rose 1.2% too, leaving an abnormal return of +0.83% that is not significant (t = 1.53, p = 0.13). |
| Main limit | Anything else that happened on the event days is in the abnormal return too, the same news often moved the basket that defines the market, and one noon rate a day cannot say exactly when the news arrived. |
| PPE concept | Information and prices |
| Skills | Event-study methods |
