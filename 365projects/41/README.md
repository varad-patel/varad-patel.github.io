# Day 41: Oil Price Shock Economy

Set an oil price jump and see which sectors are hit hardest and how it spreads.

Live at https://varad-patel.github.io/365projects/41/ (part of [365 projects in 365 days](https://varad-patel.github.io/365projects/), section "Economics × Data Science").

| | |
|---|---|
| Question | When the price of oil and gas jumps, which sectors' prices rise most, and how much of the rise arrives indirectly? |
| One finding | In the United States table for 2023 a 50% rise in the price of oil and gas raises petroleum and coal products by 26.70%, air transport by 3.77% (3.23 points of it inside the fuel airlines buy from refineries) and the household basket by 0.78%. |
| Main limit | Input proportions are fixed and every cost rise is passed on in full, so the model shows where the pressure lands, not what firms and households do about it. |
| PPE concept | Energy economics |
| Skills | Leontief input-output matrices |
| Data | U.S. Bureau of Economic Analysis |

## Files

* `index.html`: the page, including the write-up (the idea, how it works, what it cannot tell you, extensions).
* `logic.js`: the model, with no DOM code, so it can be tested on its own.
* `app.js`: the interface, built on the shared kit in `../kit/`.
* `logic.test.mjs`: tests for the model. Run them from the repository root with `node --test 365projects/41/logic.test.mjs`.

This file is generated by `scripts/build_data.py` from `meta.json` and `data/challenge.tsv`.
