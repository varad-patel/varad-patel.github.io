# Day 49: Market Structure Lab

Change the number of firms and competition type and see prices and profits shift.

Live at https://varad-patel.github.io/365projects/49/ (part of [365 projects in 365 days](https://varad-patel.github.io/365projects/), section "Economics × Data Science").

| | |
|---|---|
| Question | How do price, output, profit and lost surplus change with the number of firms and with the way they compete? |
| One finding | With demand P = 100 - Q and a cost of 20, a monopoly charges 60, two Cournot firms 46.67 and ten 27.27, and the deadweight loss falls from 25% to 11.1% to 0.83% of the competitive surplus, exactly 1/(n + 1)^2; two Bertrand firms with identical goods reach the competitive price of 20 at once. |
| Main limit | Each outcome is for one period of a game that the tool takes as given, so it cannot say which game a real industry plays or what repeated meeting would sustain. |
| PPE concept | Industrial organisation |
| Skills | Nash equilibria |
| Data | None. Everything is computed in the browser. |

## Files

* `index.html`: the page, including the write-up (the idea, how it works, what it cannot tell you, extensions).
* `logic.js`: the model, with no DOM code, so it can be tested on its own.
* `app.js`: the interface, built on the shared kit in `../kit/`.
* `logic.test.mjs`: tests for the model. Run them from the repository root with `node --test 365projects/49/logic.test.mjs`.

This file is generated by `scripts/build_data.py` from `meta.json` and `data/challenge.tsv`.
