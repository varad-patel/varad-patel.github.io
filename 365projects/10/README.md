# Day 10: Ship of Theseus Simulator

Swap parts of a virtual object one at a time, mark where you think its identity breaks, and see which theory of identity your threshold matches.

Live at https://varad-patel.github.io/365projects/10/ (part of [365 projects in 365 days](https://varad-patel.github.io/365projects/), section "Philosophy × Data").

| | |
|---|---|
| Question | At which replacement does a ship rebuilt part by part stop being the same ship, and which view of identity says so? |
| One finding | On a 46-part galley with the keel counted as 20 planks, half of the original weight has gone after 6 replacements if the frame goes first and after 41 if worn parts go first, while a head count of parts says step 23 either way. |
| Main limit | The tool sorts a visitor's mark by the view it agrees with; it cannot say which view of identity is true, and both the part weights and the 50% thresholds are conventions. |
| PPE concept | Identity over time |
| Skills | Similarity metrics, threshold analysis |
| Data | None. Everything is computed in the browser. |

## Files

* `index.html`: the page, including the write-up (the idea, how it works, what it cannot tell you, extensions).
* `logic.js`: the model, with no DOM code, so it can be tested on its own.
* `app.js`: the interface, built on the shared kit in `../kit/`.
* `logic.test.mjs`: tests for the model. Run them from the repository root with `node --test 365projects/10/logic.test.mjs`.

This file is generated by `scripts/build_data.py` from `meta.json` and `data/challenge.tsv`.
