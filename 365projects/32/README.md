# Day 32: Personal Inflation Calculator

Enter your monthly spending and get your personal inflation rate next to the official figure.

Live at https://varad-patel.github.io/365projects/32/ (part of [365 projects in 365 days](https://varad-patel.github.io/365projects/), section "Economics × Data Science").

| | |
|---|---|
| Question | How fast has the price of your own basket of spending risen, compared with the official inflation rate? |
| One finding | Over the 12 months to October 2022 the official euro-area rate was 10.6%, but the same category price changes give an invented city renter without a car 15.1% and an invented retired couple who own their home 10.4%. |
| Main limit | The tool applies the national average price change of each category to your budget shares, so it knows how you divide your spending but not the prices you actually pay. |
| PPE concept | Cost of living |
| Skills | Weighted price indices |
| Data | Eurostat HICP, ONS Consumer Prices Index |

## Files

* `index.html`: the page, including the write-up (the idea, how it works, what it cannot tell you, extensions).
* `logic.js`: the model, with no DOM code, so it can be tested on its own.
* `app.js`: the interface, built on the shared kit in `../kit/`.
* `logic.test.mjs`: tests for the model. Run them from the repository root with `node --test 365projects/32/logic.test.mjs`.

This file is generated by `scripts/build_data.py` from `meta.json` and `data/challenge.tsv`.
