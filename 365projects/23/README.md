# Day 23: Infinity Lab: Hilbert's Hotel and Cantor's Diagonal

Check in guests, coaches and infinitely many coaches and watch the room rule animate, then write a list of infinite binary sequences and see the one that is missing from it.

Live at https://varad-patel.github.io/365projects/23/ (part of [365 projects in 365 days](https://varad-patel.github.io/365projects/), section "Philosophy × Data").

| | |
|---|---|
| Question | Why can a full infinite hotel always fit infinitely many more guests, when no list can ever hold every infinite sequence of 0s and 1s? |
| One finding | Cantor's pairing rule houses infinitely many coachloads in the full hotel with no room shared or empty (room 100 goes to seat 9 of coach 5), but even the list of every repeating binary pattern misses a sequence, beginning 1010 0011 1110, that differs from row k at digit k. |
| Main limit | The page can only draw and check finite windows of infinite objects; the theorems rest on the arguments, and on accepting completed infinite sets, not on anything computed here. |
| PPE concept | Infinity, countable versus uncountable |
| Skills | Bijections, proof by construction |
| Data | None. Everything is computed in the browser. |

## Files

* `index.html`: the page, including the write-up (the idea, how it works, what it cannot tell you, extensions).
* `logic.js`: the model, with no DOM code, so it can be tested on its own.
* `app.js`: the interface, built on the shared kit in `../kit/`.
* `logic.test.mjs`: tests for the model. Run them from the repository root with `node --test 365projects/23/logic.test.mjs`.
