# Day 17: Occam's Razor Lab

Add noisy data points and watch models of rising complexity fit, with AIC and BIC picking the simplest adequate one.

Live at https://varad-patel.github.io/365projects/17/ (part of [365 projects in 365 days](https://varad-patel.github.io/365projects/), section "Philosophy × Data").

| | |
|---|---|
| Question | If a more complicated curve always fits better, how do you know when to stop adding terms? |
| One finding | Across 1,000 samples of 30 noisy points from a parabola, the residual sum of squares is lowest for the degree-8 polynomial every time, while BIC picks the true degree 2 in 865 samples and AIC in 607. |
| Main limit | The criteria only rank the candidate models they are given, and AIC and BIC answer different questions, so neither can say that the chosen model is true. |
| PPE concept | Parsimony in theory choice |
| Skills | Regression, information criteria |
| Data | None. Everything is computed in the browser. |

## Files

* `index.html`: the page, including the write-up (the idea, how it works, what it cannot tell you, extensions).
* `logic.js`: the model, with no DOM code, so it can be tested on its own.
* `app.js`: the interface, built on the shared kit in `../kit/`.
* `logic.test.mjs`: tests for the model. Run them from the repository root with `node --test 365projects/17/logic.test.mjs`.

This file is generated by `scripts/build_data.py` from `meta.json` and `data/challenge.tsv`.
