# Day 52: Auction Simulator

Bid in live auctions against bots under different formats and see revenue and strategy.

Live at https://varad-patel.github.io/365projects/52/ (part of [365 projects in 365 days](https://varad-patel.github.io/365projects/), section "Economics × Data Science").

| | |
|---|---|
| Question | Does the format of an auction change what the seller earns, and what should a bidder do in each format? |
| One finding | With four equal bidders and values spread evenly from 0 to 100, 10,000 simulated auctions (seed 52) raise an average of 60.09 first-price, 59.96 second-price and 60.20 all-pay against 60 in theory for each, with standard deviations of 12.2, 20.1 and 40.1. |
| Main limit | The bots play the equilibrium of a private-values model with evenly spread values, so nothing here says how real people bid or what happens when bidders value the item for the same reasons. |
| PPE concept | Mechanism design |
| Skills | Game theory |
| Data | None. Everything is computed in the browser. |

## Files

* `index.html`: the page, including the write-up (the idea, how it works, what it cannot tell you, extensions).
* `logic.js`: the model, with no DOM code, so it can be tested on its own.
* `app.js`: the interface, built on the shared kit in `../kit/`.
* `logic.test.mjs`: tests for the model. Run them from the repository root with `node --test 365projects/52/logic.test.mjs`.

This file is generated by `scripts/build_data.py` from `meta.json` and `data/challenge.tsv`.
