# Day 16: Argument Map Builder

Enter premises and a conclusion to draw an argument map, then remove premises to see which ones the conclusion depends on.

Live at https://varad-patel.github.io/365projects/16/ (part of [365 projects in 365 days](https://varad-patel.github.io/365projects/), section "Philosophy × Data").

| | |
|---|---|
| Question | Which premises does an argument's conclusion actually depend on, and which could be removed without it falling? |
| One finding | In a congestion-charge argument with two independent lines of support and seven premises, six premises can each be removed alone without the conclusion falling, but the one premise both lines share brings it down by itself. |
| Main limit | The map shows structure and dependence only: it cannot tell whether any premise is true or whether any inference is valid. |
| PPE concept | Argument analysis |
| Skills | Directed graphs, dependency analysis |
| Data | None. Everything is computed in the browser. |

## Files

* `index.html`: the page, including the write-up (the idea, how it works, what it cannot tell you, extensions).
* `logic.js`: the model, with no DOM code, so it can be tested on its own.
* `app.js`: the interface, built on the shared kit in `../kit/`.
* `logic.test.mjs`: tests for the model. Run them from the repository root with `node --test 365projects/16/logic.test.mjs`.

This file is generated by `scripts/build_data.py` from `meta.json` and `data/challenge.tsv`.
