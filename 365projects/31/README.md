# Day 31: What Is Driving Inflation?

Choose a country and period and see which categories of spending pushed inflation up or down, auto-updating, with a plain-English reading of each change.

Live at https://varad-patel.github.io/365projects/31/ (part of [365 projects in 365 days](https://varad-patel.github.io/365projects/), section "Economics × Data Science").

| | |
|---|---|
| Question | Which categories of household spending pushed a country's inflation up or down over a chosen period? |
| One finding | Over the 12 months to October 2022, when euro-area inflation peaked at 10.6%, housing and household energy added 4.13 points and food 2.56: two of 13 categories, with 34.7% of the basket, account for 63% of the rise. |
| Main limit | A contribution says in which part of the basket a price rise was recorded, not what caused it. |
| PPE concept | Price stability |
| Skills | Open-data pipeline, scheduled refresh, contribution decomposition |
| Data | Eurostat HICP, ONS Consumer Prices Index |

## Files

* `index.html`: the page, including the write-up (the idea, how it works, what it cannot tell you, extensions).
* `logic.js`: the model, with no DOM code, so it can be tested on its own.
* `app.js`: the interface, built on the shared kit in `../kit/`.
* `logic.test.mjs`: tests for the model. Run them from the repository root with `node --test 365projects/31/logic.test.mjs`.

This file is generated by `scripts/build_data.py` from `meta.json` and `data/challenge.tsv`.
