# Day 33: The Real Cost of Living

Enter a salary and two cities and see what each can actually buy.

Live at https://varad-patel.github.io/365projects/33/ (part of [365 projects in 365 days](https://varad-patel.github.io/365projects/), section "Economics × Data Science").

| | |
|---|---|
| Question | What does a salary actually buy in one place compared with another, and how much of the difference is rent? |
| One finding | In 2024 a salary of $100,000 in the San Francisco area, the dearest of 387 US metropolitan areas, bought what about $72,300 bought in Monroe, Louisiana, the cheapest, and housing cost 78.0% less there against 13.6% less for goods. |
| Main limit | The page has city-level price data only for the United States, so every other country is one national average and its cities cannot be told apart. |
| PPE concept | Real wages, purchasing power |
| Skills | PPP data, index numbers |
| Data | U.S. Bureau of Economic Analysis, World Bank |

## Files

* `index.html`: the page, including the write-up (the idea, how it works, what it cannot tell you, extensions).
* `logic.js`: the model, with no DOM code, so it can be tested on its own.
* `app.js`: the interface, built on the shared kit in `../kit/`.
* `logic.test.mjs`: tests for the model. Run them from the repository root with `node --test 365projects/33/logic.test.mjs`.

This file is generated by `scripts/build_data.py` from `meta.json` and `data/challenge.tsv`.
